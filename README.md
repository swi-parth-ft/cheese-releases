# Cheese for Mac

[Download Update Cheese](https://github.com/swi-parth-ft/cheese-releases/releases/latest/download/Cheese-Update-Setup.zip)

Download the ZIP, open **Update Cheese.app**, and choose **Update Cheese**. This one-time setup keeps your paired devices and settings. Afterward, update inside Cheese: **Settings → General → Check Now**.

Requires Apple silicon and macOS 14.5 or later. Cheese must already be installed in Applications.

This repository hosts signed, notarized Mac downloads and verified update metadata. The application source is maintained separately. The migration prerelease is used automatically by setup for older installations.
